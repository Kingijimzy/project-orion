## API routes

| Route | Purpose | Key checks / limits |
| --- | --- | --- |
| `POST /api/chat` | Authenticated AI chat stream, optionally with server-fetched Bybit SMC analysis or private chart image | Validates body/provider/model; images limited to 3 MB PNG/JPEG/WebP, signature checked, stored in the user-scoped private bucket, and sent only to a selected catalogue model that accepts images; no paid-model fallback |
| `GET /api/chat/images` | Authenticated private chart image delivery | Requires an image path under the signed-in user's UUID folder; Storage RLS independently checks access; response is private/no-store and MIME is allowlisted |
| `GET/POST/PATCH/DELETE /api/conversations` | User-scoped conversation list/create/update/delete | Requires Supabase user; provider/model validated |
| `GET /api/providers` | Safe provider status summaries | Never returns API keys; OpenRouter catalogue check may call upstream |
| `GET /api/models` | Model list filtered by free pricing and provider | Rejects unsupported provider; paid model availability gated by server config |
| `GET /api/markets/candles` | Bybit V5 kline history | Validates category, interval, symbol, limit; market service caches and validates data |
| `GET /api/markets/ticker` | Bybit V5 current ticker and 24-hour change/high/low/volume values | Validates category/symbol and response; short per-symbol cache; does not fabricate fallback prices |
| `GET /api/markets/symbols` | Bybit V5 instrument search | Validates category/query and caches symbol results |
| `POST /api/smc/analyze` | Multi-timeframe Bybit SMC scan | Validates category/symbol/timeframe; saves snapshot only with authenticated Supabase access |
| `POST /api/smc/backtest` | Deterministic historical replay of the SMC rule set with empirical target/stop base rates | Validates category/symbol/timeframe; bounded evaluation budget spread across the whole series; 60-second cache; uses the signed-in user's selected profile when available; returns explicit sample-size and modelling caveats |
| `GET /api/smc/analyses` | User-owned saved analysis search | Requires Supabase auth and RLS |
| `GET/POST /api/strategy-profiles` | User-owned strategy profiles | Requires Supabase auth; input settings validated |
| `GET/POST /api/journal` | User-owned journal records | Requires Supabase auth; bounded and validated writes |
| `POST /api/journal/[id]/review` | Append a review to a user-owned entry | Requires Supabase auth; RLS ties review to the owned entry |
| `GET /api/forex/rates` | Frankfurter v2 daily reference rates | Validates currencies and returned rows; labels reference-only; short edge cache |
| `GET /api/forex/candles` | Twelve Data forex OHLC candles | Validates pair, interval, count, values, UTC timestamps, ordering and duplicates; 60-second cache; returns unavailable when `TWELVE_DATA_API_KEY` is missing |
| `GET /api/news` | Official BLS and Federal Reserve RSS/Atom release headlines | Source allowlist and HTTPS links; bounded item/title/summary sizes; partial source outages are surfaced |
| `GET /api/news/calendar` | Upcoming BLS scheduled releases and Federal Reserve FOMC date ranges (120-day horizon) | Parses BLS ICS, falls back to official BLS month-list pages, and parses Fed calendar HTML; source outages surfaced; no invented impact or actual/forecast/previous figures |
| `POST /api/livekit/token` | Short-lived user/room-scoped LiveKit token | Requires Supabase auth; keeps signing secret server-side |

No route currently handles automated order execution. Bybit public WebSockets are consumed directly by the Markets client. Screenshot privacy depends on applying the new storage migration; no cross-user Storage test has been run against the connected Supabase project.

## Supabase and privacy

The migrations define private conversations/messages, strategy profiles, SMC analysis snapshots/explanations, journal entries, and journal reviews with owner-scoped RLS. Server routes use the authenticated user and do not need a service-role key. Anonymous requests previously returned no visible rows, but that is not a two-user isolation test. Signed-in writes/reads, cross-user denials, and storage privacy remain unverified because no controlled pair of test users/storage bucket is available here.

Environment configuration uses `.env.example`; `.env.local` is ignored by `.gitignore` and not tracked. Only Supabase URL and publishable/anon key use the `NEXT_PUBLIC_` prefix. OpenRouter, Gemini, and LiveKit secrets remain server-side.

## Verification evidence

- `npm test`: 84 passing, 0 failing in this worktree; covers image validation/provider modality, official news and calendar parsing/failures, FX rates/session schedule and Twelve Data candle parsing/route failures, Bybit REST/ticker/WebSocket parsing, SMC profile resolution, scenario derivation (engine-sourced levels only, no fabricated confidence), backtest trade resolution and replay consistency, chart annotation visibility, journal, and provider behavior.
- Historical replay fix: the multi-timeframe engine previously used the raw input's last candle (ignoring the `asOfTimestamp` cutoff) when judging candidate expiry, which forced nearly every replayed point to Expired and would have blocked historical backtests and saved-history replay. It now uses the replay-filtered latest closed candle; a regression test asserts that appending later candles does not change an as-of assessment.
- SMC backtest live smoke (2026-10-17): replaying the default Orion Baseline profile over live Bybit `BTCUSDT` 1H history produced 200 evaluation points in about 3 seconds; the strict default found one Qualified state and a conforming short/long profile produced 55 Qualified states with a 29% target-hit rate at 2R. Win rate alone is not an edge; these are raw sample statistics with the response's own caveats.
- `npm run typecheck`: PASS after final UI/API changes.
- `npm run build`: PASS; production output includes `/api/news`, `/api/forex/rates`, LiveKit, existing app routes, and PWA manifest.
- Frankfurter v2 direct upstream request: HTTP 200 with dated USD rates during development; route unit tests cover validation, malformed data, and network/upstream failures.
- Twelve Data candles: adapter and UI are implemented, but no Twelve Data key is configured in this workspace, so live forex candle retrieval was not run. Mocked tests cover successful candles, UTC timestamps, malformed payloads, missing credentials, and quota errors.
- Forex session schedule is a timezone-aware indicative estimate based on [OANDA's published US hours](https://www.oanda.com/us-en/trading/instruments/); automated tests cover Sunday open, Friday close, daily maintenance break, weekend closure, and daylight-saving time. It does not detect holidays, broker-specific changes, or quote-feed health.
- Official news source check: BLS Employment/CPI Atom feeds and Federal Reserve monetary-policy RSS all returned HTTP 200; parsed 39 sourced items total with no unavailable sources. Unit tests cover parsing, safe links, and partial upstream failure.
- Official calendar source check (2026-10-17): BLS ICS returned HTTP 403, triggering the official month-list fallback; the Federal Reserve FOMC calendar returned events. The loader parsed 30 future events (29 BLS releases and one FOMC date range) with no unavailable sources. Schedule values do not include actual/forecast/previous or impact ratings; unit tests cover Eastern-time/DST parsing, month-list fallback, and source failures.
- Bybit live WebSocket smoke: connected to the official linear public endpoint, received subscription acknowledgement and one `kline.1.BTCUSDT` candle.
- Bybit live ticker smoke: the public V5 linear ticker endpoint returned a validated `BTCUSDT` quote and 24-hour change; the app caches each symbol/category for five seconds and shows explicit refresh errors.
- OpenRouter vision smoke check: the live catalogue confirmed `nvidia/nemotron-3.5-super-vl:free` had zero prompt/completion price and image input while paid access was disabled; a one-pixel PNG request streamed an image description. This verifies the provider/model path, not accuracy on complex user screenshots.
- `npm audit`: no advisories after pinning PostCSS to patched `8.5.23` (overridden transitively for Next.js). Re-run before merge because advisories change.
- Existing production URL `https://project-orion-murex.vercel.app/` returned HTTP 200 and rendered Orion in the session browser. This is the current deployed app, not this feature branch.
- A real OpenRouter image/vision generation request, mobile viewport checks, a feature-branch deployment preview, authenticated Supabase behavior, LiveKit worker startup/session, and private storage: not verified. This branch's preview requires Vercel access and could not be inspected.
